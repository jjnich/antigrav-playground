# Antigravity Playground

Welcome to the Antigravity Playground! This repository serves as a sandbox for building, testing, and collecting various applications and tools created alongside the Antigravity AI assistant.

As new projects are built, they will be bundled into their own directories within this repository.

## Existing Projects

### 🌤️ Weather Widget (`/weather-widget`)
A sleek, glassmorphic desktop weather widget built with **Electron**, **React**, and **Vite**. 

**Features:**
- **Frameless Desktop App:** Runs silently as a transparent, always-on-desktop widget.
- **NWS API Integration:** Live current temperatures and hourly forecasts fetched directly from the National Weather Service.
- **Live Radar Map:** Integrates an auto-updating Iowa Environmental Mesonet (IEM) NEXRAD radar feed using Leaflet.
- **Auto-Refresh:** Seamlessly refreshes weather and map tiles every 15 minutes.

**How to Run:**
```bash
cd weather-widget
npm install
npm start
```
*(Or simply double-click the Windows Shortcut if you generated one!)*
